# Saving, trimming and resizing video

## Pick where a new video goes

1. Use **Add video** to import or record.
2. Choose **This phone** for a separate local file, or **Online storage** for an upload.
3. For online storage, select the exact named folder, such as Salsa or Bachata. Both
   can be connected to the same account. Dance style and artist labels do not route files.
4. Choose **Keep a phone copy after upload**, then **Upload & add to library**.
5. Wait for **UPLOAD CONFIRMED** and check its folder name. If interrupted, the phone
   file remains available; open it and use **Upload to my storage** to resume.

In **Storage**, connect each folder separately and enable **Allow uploads to my Drive**
for a Google account that should accept uploads. A local-only save performs no upload.
Online-only saves remove BailaCue's temporary file after confirmation. This does not
remove a separately imported original from Photos/Files or another provider.

## Trim on the playback line

1. Open a video and choose **Trim on timeline**.
2. Drag the two handles to set start and end. The picture previews the selected edge.
   The selected times are shown beneath the line; precise numeric fields remain under
   **Extra options → Keep the good part**.
3. Choose where to save the new clip: phone storage or a particular cloud folder.
4. Press **Save selected clip**. BailaCue creates a new MP4 without changing the original.
   An online destination starts its upload automatically after native export.

Cloud videos must be downloaded before native editing. An online video's sole source
is preselected when opening its editor; multiple folder memberships require a choice.
If you switch to a downloaded phone copy, review the destination before saving.
Phone clips can also be saved to Photos or shared through **Share / Save file**.
Timeline handles support accessibility adjustment; browser preview handles support
keyboard arrows. The minimum exportable section is 0.25 seconds.

## Resize the player

Drag the grip immediately below the picture up or down. Screen readers offer increment/decrement actions; browser keyboard arrows adjust height. The picture keeps its aspect ratio. Use **Full screen** for an immersive view. Mirror uses the native TextureView while control labels stay readable. Size presets and Count it out were removed. Resizing, speed and Mirror do not change the exported MP4.

Video details, dance, labels and all star ratings appear directly after playback controls. **Extra options** holds downloads, class/artist context, comparison, sections and unified **Notes & moments**. A note can be untimed; attaching a timestamp creates a seekable moment. Existing notes/bookmarks migrate without duplicate records.

Native exports, provider uploads and Photos saving require the Android/iOS app.
The web preview reports these limits and retains phone-imported media after an upload
attempt fails. See [verification](VERIFICATION.md) for tested behavior and live-provider
and iOS limits.
