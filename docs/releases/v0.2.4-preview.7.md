Download **BailaCue-v0.2.4-build7-preview.apk** under Assets and open it on an Android phone. This is an internal preview signed with a test certificate; Expo Go and a development server are not needed.

New in this update:

- Google app-registration failures (including the reported `DEVELOPER_ERROR`/code10) now show a clear explanation, an Import from Files action and connection setup help. Nine native SDK mock regressions verify the error mapping and account isolation. **This does not replace the required Google Cloud OAuth registration. Direct Drive sign-in remains unavailable until the app owner registers this package/signing certificate.**

- Searchable label dropdowns in video import, video details and cloud-folder defaults.
- Choose existing labels or create a new video-type, artist or custom label. Select several labels and remove individual ones with their × button.
- Saved video and folder labels become suggestions elsewhere in your current library. Matching ignores case and extra spaces while preserving artist accents and punctuation. Existing saved labels remain compatible.

On import, choose labels before **Add to my library**. On an existing video, open **The little details**, choose labels, then **Save details**.

Validation: TypeScript, ESLint, 80 unit/database tests across nine suites, web export and four Chromium journeys passed locally. The new browser journey verifies artist/video-type creation, existing-label reuse, duplicate prevention, editing and reload persistence. The Android publication workflow passed all eight Google ARTEMIS controller checks against this APK, including label creation/reuse, real document import, named looping, separate native MP4 export, unchanged original bytes and saving to Photos. No autonomous Gemini session is invoked.

This retains the previous preview's video editing, personal Drive/Dropbox folder selection, online/phone copies, practice features, icon and branding. Each user connects their own storage account. BailaCue's one-time Google/Dropbox OAuth app registration is still required for direct provider connections; the phone's Files picker works independently. iOS needs an Apple-signed build. Live provider transfers and real two-user Me+ account acceptance remain unverified; automatic sync and new-video server push remain pending.
