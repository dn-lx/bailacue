# BailaCue 0.3.0 · build27

A local-first practice library with personal recovery storage and clearer controls.

- Android/iOS metadata now lives in SQLite. Existing phone libraries migrate into
  separate local profiles; original records, video files and provider credentials
  are preserved. BailaCue no longer needs Me+ login or a Supabase connection.
- Export/import reviewed, checksummed metadata backups. Save dated copies to your
  own Drive/Dropbox folder, including a separate folder just for recovery.
- Optional Google Sheets two-way sync includes editable labels, config, titles,
  ratings and video labels, complete recovery data, dated versions, offline retry,
  last-success/status and explicit conflict review.
- Manage reusable labels and remove them globally with confirmation. Selected
  video labels now show a clear Remove action.
- Compact headers and Library cards, clearer navigation and restrained native
  press, entrance and progress motion. Reduced motion and centered chip rows are
  supported. The approved blue/black b/play icon remains.
- Save details and custom dance creation wait for durable storage before confirming.

Use **Settings → Backups & recovery** for metadata storage and **Manage labels**
for global label deletion. Backups do not contain video files or sign-in secrets.
Keep your original videos in storage you control before uninstalling.

Google Sheets API must be enabled in the Google Cloud project owning BailaCue's
OAuth registration. Each user chooses their own Google account and spreadsheet.
Live private-account Sheets/Drive/Dropbox acceptance has not been performed here;
transport, retry, merge and history behavior are tested with controlled API replies.
Background sync depends on OS scheduling and internet access. Sheets cannot
provide database transactions between devices; simultaneous edits can require recovery.

This preview is published only after the bundled APK passes the Google ARTEMIS
native release gate, including actual video trim/export/original preservation and
SQLite persistence. Detailed evidence and source checks are recorded in
[verification](https://github.com/dn-lx/BailaCue/blob/feat/bailacue-mobile-foundation/docs/VERIFICATION.md). The optional public YouTube attempt may be
provider-blocked; it is never counted as a pass. Full playlist pagination needs an
optional device YouTube API key.

Install over the previous preview to keep app-private data. No production Me+
data has been changed or deleted. This is a preview APK, not a Play Store release.
iOS signed device distribution still requires Apple signing and separate runtime review.
