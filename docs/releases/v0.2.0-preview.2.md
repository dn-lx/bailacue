Download **BailaCue-v0.2.0-build2-preview.apk** under Assets and open it on an Android phone. Allow installation from the browser/files app when Android asks. No Expo Go or development server is needed. This is an internal test build signed with a preview certificate.

- Personal Google Drive/Dropbox account and folder selection; stream online or keep selected phone copies.
- Folder defaults, labels/ratings, refresh preservation, source filters, download controls and explicit writable upload destinations with recoverable uploads.
- New trimmed MP4 exports as separate videos, Photos/file saving, comparison, practice reminders/quiet hours and optional device lock.
- Existing local import/recording, speed/mirror/loops, notes/bookmarks, collections, Daily Picks and practice history.

**One-time connection setup is still required.** Each user connects their own account, but BailaCue must first be registered as an OAuth app with Google/Dropbox. No credentials are bundled. See [Cloud storage setup](https://github.com/dn-lx/BailaCue/blob/feat/bailacue-mobile-foundation/docs/CLOUD-STORAGE.md). You can immediately import from installed cloud apps through the phone's Files picker.

The Me+ account/sync/sharing API and private tables are prepared and locally tested; production deployment is pending separate approval required by the brief. New-video server push and automatic sync are not enabled. iOS needs a separate Apple-signed build.
