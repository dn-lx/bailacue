# BailaCue 0.2.21 · Android preview build26

Implements the approved round-2 requirements. Install over the previous preview to
keep your device library.

- YouTube playlist discovery explicitly cues the official playlist without starting
  playback. An invalid Data API key can fall back to the player's visible list.
- Add selected videos is beside playlist setup. Success appears after the Library
  write completes, with Open Library, preserved selections on failure, and retry.
  Partial player-list refreshes retain existing memberships and personal edits.
- Chip groups and shorter wrapped rows center across playback, Library filters, Practice, Settings and imports.
- Long YouTube titles use a compact two-line heading with Show full title.
- YouTube has a resize grip and accessible adjustment, plus a visible Full screen
  action and Android Back handling. The same player stays mounted, preserving
  video position, play/pause and supported speed across those layout changes.
- The approved concept05 lowercase b/play icon replaces BC. Transparent light/dark
  in-app marks, adaptive foreground, monochrome, splash, logos and platform exports
  regenerate from a clean SVG master. Platform-required launcher backgrounds remain separate.

player's visible list may be limited; the app discloses this and offers setup/retry.
