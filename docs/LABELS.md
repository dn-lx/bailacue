# Dance types, labels and artist names

Dance types are shared across source setup, import, details, Library, Daily Picks
and Practice. Salsa/Bachata are defaults; **Add dance type** creates Tango or any
other name. Types are independent of storage folders. A source has an explicit
default; refreshing preserves edits. Legacy unclassified videos remain reachable
through secondary Library filters without a permanent Other dance chip.

Open **Choose or create labels**, search, then Select an existing/suggested label or
Create a custom one. Several labels can be selected; × removes one from this editor.
Save the import/folder or **Save details** on an existing video. Details follow
playback controls; less-used tools sit under **Extra options**.

Suggestions are grouped into Bachata/Salsa vocabulary, traditions, technique, video
type and level. They are optional choices, not automatic tags. Names of artists or
teachers are user supplied; uploader names/people in frames are not inferred as
artist tags. Original accents and punctuation stay intact. Case, whitespace and
Unicode equivalents do not create duplicates. Labels are not split at commas.
Footwork/Shines and Dominican/Dominicana matching use explicit known aliases while
stored custom labels remain intact.

Source defaults tag newly discovered/imported items, not every existing video.
Refresh preserves personal labels. Library uses a searchable label filter combined
with dance, exact star, storage and search filters. Practice and optional Daily gates
support Match any/all. Saved labels and custom dance IDs travel with manual metadata
sync; no additional production tables are needed.
