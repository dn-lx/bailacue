# Daily Picks · dances, ratings and saved choices

The default is one video per selected dance, independent of folder count. Two
Salsa folders and one Bachata folder still give one Salsa and one Bachata pick.
Settings offers advanced **One per selected source**, or an explicit total count.
Selected dances, available media, minimum stars, optional source selection and
optional required labels are eligibility gates in every mode. Match any/all labels
is explicit. YouTube is included only after its separate online opt-in.

Unrated videos count as 5★ until rated. They remain visibly Unrated. Legacy scanned
cloud videos automatically assigned 3★ without a rating marker are unrated; choose
3★ explicitly if intended. The full 1–5 controls and Unrated are available directly
on a Daily card and in details. Library rating filters select exact stars instead
of minimum thresholds.

Among eligible videos not recently picked, stars rank first. Preferred labels and
practice recency break ties; learning status and old More/Less feedback no longer
influence the score. A recent-pick cooldown is applied independently per dance or
source slot. If all eligible items in a slot are recent, its best eligible item can
repeat. Minimum stars never silently drop. Empty slots explain what is missing;
one underlying video cannot fill two slots.

Valid choices are saved for the local calendar day. Update today’s picks explicitly
replans. Changed eligibility/mix or a strategy upgrade can replan; a newly available
missing slot fills without replacing existing valid picks. Skip today stays respected
and does not rate a video. A changed rating alone retains a valid saved selection
until refresh, unless it falls below the eligibility threshold.

Daily Picks are rating-first recommendations, not a random queue. [Practice](PRACTICE.md)
uses a separate weighted permutation with balanced dance turns. Actual playback
updates practice recency. Manual metadata sync includes ratings/preferences/picks;
automatic cross-device merging and server push remain future scope.
